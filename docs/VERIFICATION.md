## 未検証・外部作業

E2Eの1スキップはWebKitの実OSクリップボード許可確認です。同ブラウザのコピー値・成功／失敗通知はモックで検証しています。Chromiumでは実Clipboard APIへMarkdown・LaTeXを書き込み、読み戻して確認しました。WindowsがLFをCRLFへ変換するため、実OSからの読み戻しだけ改行コードを正規化しています。APIへ渡す値の完全一致は別テストで確認しています。

古い試行のサンプルHTMLが出力先に残るケースを生成物検証で検出し、ビルド前の出力初期化で修正しました。その後、本番とプレビューを別々に再生成して検証しています。

- 実機iPhone Safari・Android Chrome。
- Cloudflare連携、GitHub上のCI実行、Pagesへのデプロイと本番URL・HTTPステータス。
- 実在する過去問の公開前レビューと公開。実問題100件は下書き、架空サンプル3件は非公開です。原本に見られる表記の不一致は取り込み記録に記載しています。
- 正式ドメイン・公開連絡先の設定。
- Lighthouse・Core Web Vitals測定。

制限環境のWindowsではtsxが`uv_os_get_passwd`エラーになるため、検証コマンドは通常実行環境で実行。Astro telemetryはnpm scripts内で無効化しています。
